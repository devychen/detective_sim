RESULTS 12/22

I have re-extracted the dialogue using an LLM-based pipeline and 
conducted a systematic data diagnostics step before training.

The resulting dataset contains ~28k utterances (~630k tokens).
Each of three main character has around ~120k–150k tokens.
The classifier had access to sufficient data to learn stylistic signals, if present.

Fewer than 2% of utterances exceed 128 tokens, suggesting minimal truncation-induced information loss.
While some noise and duplication remain (10–13%), these are consistent with known LLM extraction artefacts and can be addressed via lightweight preprocessing.
And Japp esp. has noise around 18-20%, given that he has the fewest tokens (60k) and 
there already is another main sidekick from Agatha Christie's work (Hastings), I'd like to delete his data.
