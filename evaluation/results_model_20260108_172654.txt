 出现 prob_ci_low < 0 或 prob_ci_high > 1

例如：

prob_mean = 0.4960
prob_ci_low = -0.0482
prob_ci_high = 0.4679

不是错误，原因是：

你用的是 normal-based CI (mean ± 1.96·SEM)

prob 是 bounded [0,1]，但 CI 没 enforce bound

👉 在论文中你可以写一句：

Confidence intervals were estimated using normal approximation and are therefore not constrained to the [0, 1] range.

如果你愿意，我可以教你 beta CI / bootstrap CI，但现在这套已经完全可 defend。

t_stat = slope / se_slope

近似正态
